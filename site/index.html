How it works

Everything sensitive stays on the device.

Only structured, human-reviewable detections that clear a fleet-confidence gate can ever sync. Frames stay in memory.

Camera→Vehicle & plate detect→OCR + multi-frame fusion→Fleet-confidence gate→Review outbox→CloudKit / REST mirror
ON-DEVICE

Local models

Vision text recognition plus CoreML detectors. No cloud inference on camera frames.

GATED

Fleet-only ingestion

A redaction gate drops private-plate reads before anything leaves the device. Location stays coarse until a fleet match.

SOURCED

Provenance everywhere

Agency, unit and cost enrichment carries a citation to a public record. No citation, no enrichment.

REVIEWED

Humans decide

Borderline cases go to a review queue with intact local evidence and a content hash.

macOS · PlateWatch Hub

One console for public camera feeds.

Browse and map public feeds, pin favorites, block bad views, and open any camera in Live. Records & FOIA drafts and tracks fleet requests. A local, authenticated MCP interface lets coding agents inspect feeds and records under review rules.

Platforms

Apple-first today. Everywhere next.

The reference server already runs anywhere Docker does. What is missing is the on-device pipeline outside Apple silicon, because every shipped model is CoreML. Exporting to ONNX and TFLite is the gate for the rows below marked planned.

The maintainer has Apple hardware only. Windows, Linux and Android are verified through CI runners, emulators and virtual machines, and through community testers. That is where you can help.

Principles

Encoded in the data layer, not just the docs.

Watches the powerful, never the privatePublic officials in their public capacity are fair subject matter. Private individuals, their plates and homes are out of scope absolutely.
Public records onlyFleet registries, FOIA releases, rosters, auction listings. Never DMV or data-broker data.
On-device firstNo telemetry, analytics SDKs, frame uploads or third-party trackers.
Evidence qualityEvery sighting is content-hashed and timestamped, with its sources.
Help test

We need people on hardware we do not own.

PlateWatch is pre-alpha and developed on Apple devices. If you run Windows, Linux, Android or Wear OS, a short test report is worth more than code.

Linux & Raspberry Pi

  • Run the Docker reference server
  • Run the Python edge agent against it
  • Report distro, hardware and what broke

Windows

  • Run the server in WSL or Docker Desktop
  • Open the web explorer in your browser
  • Tell us which native client you would use

Android & Wear OS

  • Install the read-only Android client
  • Report device, OS version and screens that fail
  • Tell us what capture should do

Everyone

  • Point out camera sources worth adding
  • Review the legal and ethics rules
  • Open an issue with what you found
