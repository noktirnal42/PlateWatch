## General fixes learned from this audit

1. A 200 HTML homepage at `/robots.txt` is a failed policy fetch, not an empty allow policy. Retry transient lookup failures within one minute.
2. Strip the UTF-8 BOM before parsing: Utah's policy includes it before the first `user-agent` directive.
3. Keep HTTP errors distinct from transport/TLS errors. Caltrans's explicit publication exception only applies to a real HTTP 5xx and exact cited image branches; a network failure supplies no permission.
4. Preserve each camera's own location, source citation, cadence and terms through Live analysis. Never substitute this Mac's home position for an out-of-state web camera.
5. Snapshot freshness and video availability are independent. Do not invent `.m3u8` URLs from RTMP names, upgrade arbitrary hosts, or interpret a moving thumbnail as validated video ingest.

Canadian catalogue options (DriveBC and Newfoundland/Labrador) were removed from the Hub menu at the owner's request. Their package parsers remain for compatibility; no Canadian camera records were present in the checked local catalogue. This is a targeted access audit, not exhaustive US coverage.

Terms review is collapsed by default so many pending hosts do not crowd out the feed list.
